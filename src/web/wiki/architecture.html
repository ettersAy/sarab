Architecture

System Diagram

Browser (SSE) ──→ Express Server (port 3457)
                    │
                    ├── /api/jobs/*      → JobStore (JSONL + markdown)
                    ├── /api/projects/*  → ProjectStore (filesystem dirs)
                    ├── /api/tickets/*   → TicketStore (JSONL + markdown)
                    ├── /api/chatbot/*   → ChatStore (JSONL)
                    ├── /api/settings/*  → SettingsStore (JSON)
                    ├── /api/sessions/*  → SessionStore (JSONL)
                    ├── /api/prompt/*    → Executor (AI call)
                    ├── /api/events      → SSEManager (real-time)
                    └── /wiki/*          → Static HTML docs

QueueManager (poll loop, concurrency control)
  └── ClaudeExecutor (spawn claude CLI)
  └── DeepSeekExecutor (HTTP to OpenAI-compatible APIs)

Data Flow: Job Execution

1. User submits prompt via /api/jobs POST
2. JobStore persists to JSONL + markdown (if project-linked)
3. SSE broadcasts "job created" to all clients
4. QueueManager tick picks up pending job
5. ProjectStore resolves cwd, SessionStore resolves session
6. ClaudeExecutor spawns `claude -p "prompt"` with heartbeat
7. stdout chunks → LogStore.write() + SSE heartbeat events
8. On completion → JobStore.update() + SessionStore.create() + SSE broadcast

Error Handling Architecture

AppError (base)
  ├── NotFoundError (404) — Resource not found
  └── ValidationError (400) — Invalid input

Express error middleware catches AppError instances.
Uncaught executor throws → try/catch in processJob → job-failed event.
Frontend unhandledrejection → toast notification + console.error.
