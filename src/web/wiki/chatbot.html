Project Chatbot

SARAB's project chatbot lets you ask natural-language questions about any registered project. The AI answers using the project's own documentation files as context — no more digging through folders to find that one config file or architectural note.

How It Works

  1. Select a project — pick from the project dropdown in the chatbot view.
  2. Ask a question — type any question about the project's purpose, structure, or configuration.
  3. AI answers with context — the backend loads the project's context files, builds a prompt combining the question + file contents + conversation history, and sends it to the configured AI provider (same provider used for job execution).
Fixed: multi-turn conversation. Earlier versions only sent the latest question to the AI with no chat history. The chat store now correctly persists the full conversation, and every turn includes prior messages in the prompt. The AI sees the entire exchange and can refer back to earlier context.

Context Loading

When a question is asked, the backend loads relevant context from the project before calling the AI. This is controlled by the contextFiles field in Project Settings.

Configuration

Each project can specify an array of glob patterns or file paths under contextFiles in its project.json:

{
  "name": "my-project",
  "rootPath": "/home/user/my-project",
  "contextFiles": [
    "README.md",
    "ARCHITECTURE.md",
    "docs/**/*.md",
    "src/config.ts",
    "package.json"
  ]
}

Loading Logic

The loadContextFiles() function (src/chatbot/context.ts) resolves each pattern against the project's rootPath, expands globs, and reads matched files. The resolved file list is cached per project and re-scanned on each ask.

Safety Checks

Three guardrails prevent abuse:

  • Path traversal blocked — any resolved path that escapes the project root directory is silently dropped. Symlinks are not followed outside the root.
  • 50 KB per file limit — files larger than 50 KB are truncated to 50 KB. A note is appended to the content indicating truncation.
  • 100 KB total context limit — if the combined content of all matched files exceeds 100 KB, files are included in order of match priority until the limit is reached. Excess files are noted in the prompt so the AI knows context was trimmed.

Multi-Turn Conversation

The chatbot maintains full conversation history. Each exchange is stored as a ChatConversation containing an ordered list of ChatMessage objects (role + content). On every ask:

  1. The question is appended to the conversation's message list.
  2. The backend constructs a system prompt from Project Settings (templates.reflection), prepends the loaded context, then appends the full message history.
  3. The AI response is saved as a new assistant message in the conversation.
Context window note. Long conversations may exceed the AI provider's context window. The system clips history to the last 20 messages (10 turns) to stay within limits. This is configurable via maxHistoryMessages in the chatbot config.

Quick Actions

The chatbot view provides one-click quick action buttons for common questions. These work without typing:

What is this project about?

Summarizes the project's purpose from README and key docs.

Summarize architecture

Reads ARCHITECTURE.md and code structure to produce a high-level overview.

Key files

Lists the most important source files and what each does.

How do I run this?

Extracts setup, build, and test commands from docs and package.json.

List dependencies

Reads package.json and summarizes key runtime dependencies.

Show me the config

Loads configuration files and explains settings.

Data Model

Chat data is stored in src/storage/chatbot.ts as JSONL files under the .sarab/ directory.

TypeFieldsDescription
ChatConversation id, projectId, title, createdAt, updatedAt, messageCount A single Q&A session tied to a project.
ChatMessage id, conversationId, role ("user" | "assistant"), content, timestamp Individual message within a conversation.

Conversations are stored as a JSONL of ChatConversation records. Messages are stored in a separate JSONL file keyed by conversationId. This keeps message lookups fast without loading unrelated conversations.

API Endpoints

MethodPathDescription
POST /api/chatbot/ask Ask a question. Body: { projectId, conversationId?, question }. Returns the AI response. Creates or resumes a conversation.
GET /api/chatbot/conversations/:projectId List all conversations for a project, sorted by updatedAt descending.
GET /api/chatbot/messages/:conversationId Get all messages for a conversation, ordered by timestamp ascending.
DELETE /api/chatbot/conversations/:conversationId Delete a conversation and all its messages.

System Prompt Customization

The system prompt sent to the AI is built from the templates.reflection field in Project Settings. This lets you tailor the AI's behavior per project:

// Project Settings → templates.reflection
"You are a helpful assistant with deep knowledge of this project. "
"Answer questions about the codebase, architecture, and configuration. "
"Be concise but thorough. Use code snippets when relevant."

If no custom template is set, a default system prompt is used that instructs the AI to answer factually based solely on the provided context files.
