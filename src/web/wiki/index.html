SARAB Smart AI Request Automation Bot

A web UI for queuing and executing Claude CLI prompts with real-time SSE monitoring, a Kanban ticket board, project context management, and an AI-powered project chatbot.

⚡ Job Execution

Queue prompts, heartbeat-based idle detection, stop/resume, live log streaming, retry with backoff.

📋 Kanban Board

Drag-and-drop ticket management with subtickets, priorities, project filtering, and markdown persistence.

💬 Project Chatbot

Ask questions about any project with AI grounded in project documentation. Multi-turn conversation with context.

🗃 Filesystem Persistence

Projects as directories, tickets and prompts as markdown files. Survives restarts. Atomic writes.

🔧 AI Providers

Multi-provider support (Claude CLI + OpenAI-compatible). Per-project defaults. Prompt improvement.

🛠 Testing

124 tests: 24 unit (Node test runner) + 100 Playwright (API + UI). Smoke tests. JS syntax checks.

Quick Start

npm install
npm run dev                  # http://localhost:3457
npm run test:unit            # 24 unit tests
npx playwright test          # 100 browser + API tests
./scripts/SarabWakeUp        # Start server with health check
./scripts/sarabHealth        # Check server status

Architecture at a Glance

Browser (SSE) → Express → QueueManager → ClaudeExecutor (spawn claude CLI)
                       → JobStore + ProjectStore + TicketStore + ChatStore
                       → Filesystem: /srv/dev/sarab/projects/
