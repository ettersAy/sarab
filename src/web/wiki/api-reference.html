API Reference Base URL: http://localhost:3457/api

All endpoints are prefixed with /api. Requests and responses use JSON. Error responses follow the AppError shape: { error: string, message: string }.

The SSE event stream at GET /api/events provides real-time job lifecycle, heartbeat, and stats updates over a persistent connection.

Jobs

MethodPathDescriptionRequest / Response
GET /jobs List all jobs, newest first Query: ?limit=N&offset=N. Response: Job[] or { jobs, total, limit, offset } when paginated.
GET /jobs/stats Queue statistics Response: { pending, running, completed, failed, cancelled, stopped, total }
GET /jobs/:id Get a single job by ID Response: Job
GET /jobs/:id/detail Get job with log content Response: { job, logContent }
GET /jobs/:id/log Get job log only Response: { jobId, content }
POST /jobs Create a new job Body: { title, prompt, model?, timeoutMs?, idleTimeoutMs?, maxRetries?, tags?, projectId?, sessionId?, sessionMode?, executionMode? }. Returns Job.
PATCH /jobs/:id Edit a pending/completed/failed job Partial body: { title?, prompt?, model?, tags?, timeoutMs?, idleTimeoutMs?, maxRetries? }. Cannot edit running jobs.
POST /jobs/:id/cancel Cancel a pending job Returns updated Job with status cancelled
POST /jobs/:id/stop Stop a running job (SIGTERM) Returns updated Job with status stopped
POST /jobs/:id/resume Re-queue a stopped job as pending Returns updated Job
POST /jobs/:id/retry Retry a failed job Returns updated Job with status pending
POST /jobs/:id/duplicate Duplicate an existing job Creates copy with " (copy)" appended to title. Returns Job.
DELETE /jobs/:id Delete a job and its log Cannot delete running jobs. Response: { deleted: true }

Projects

MethodPathDescriptionRequest / Response
GET /projects List all projects, newest first Response: Project[]
POST /projects Create a project Body: { name, rootPath, settings? }. Returns Project.
GET /projects/:id Get a single project Response: Project
PUT /projects/:id Update project settings Body: partial Project. Returns updated Project.
DELETE /projects/:id Delete a project Response: { deleted: true }
GET /projects/:id/jobs List jobs for a project Response: Job[] filtered by projectId
GET /projects/:id/sessions List sessions for a project Response: Session[] filtered by projectId

Tickets (Kanban)

MethodPathDescriptionRequest / Response
GET /tickets List tickets with optional filters Query: ?projectId=X&column=backlog&parentId=Y. Response: Ticket[]
POST /tickets Create a ticket Body: { title, description?, column?, priority?, projectId?, parentId?, tags? }. Columns: backlog | ready | in-progress | paused | testing | done. Priority: low | medium | high | critical.
GET /tickets/:id Get a single ticket Response: Ticket
PATCH /tickets/:id Update ticket fields Partial body. Returns updated Ticket.
DELETE /tickets/:id Delete a ticket Response: { deleted: true }
POST /tickets/:id/move Move ticket to a different column Body: { column }. Returns updated Ticket with timestamp updates.
GET /tickets/:id/subtickets Get child tickets Response: Ticket[] where parentId matches :id

Chatbot

MethodPathDescriptionRequest / Response
GET /chatbot/conversations List conversations for a project Query: ?projectId=X (required). Response: ChatConversation[]
GET /chatbot/conversations/:id/messages Get all messages in a conversation Response: ChatMessage[]
DELETE /chatbot/conversations/:id Delete a conversation and its messages Response: { deleted: true }
POST /chatbot/ask Ask a question to the project chatbot Body: { projectId, question, conversationId?, model? }. Loads project context files, builds prompt with conversation history, executes AI call. Returns { conversationId, message, contextUsed, totalContextSize, truncated }.

Settings & Providers

MethodPathDescriptionRequest / Response
GET /settings Get full settings object Response: AppSettings with providers, defaults, prompt improvement config
PUT /settings Replace all settings Body: AppSettings. Validates defaultProviderId exists in providers. Returns updated settings.
GET /settings/providers List all AI providers Response: AIProvider[]
POST /settings/providers Add a new AI provider Body: { name, type, apiKeyEnvVar, defaultModel, enabled?, isDefault?, baseUrl?, claudeCmd?, claudeFlags? }. Type is claude-cli or openai-compatible.
PUT /settings/providers/:id Update an AI provider Partial body. Setting isDefault: true clears default from all others.
DELETE /settings/providers/:id Remove a provider Cannot delete the default provider. Response: { deleted: true }
POST /settings/providers/:id/default Set a provider as default Clears default on all other providers. Returns AIProvider.

Sessions

MethodPathDescriptionRequest / Response
GET /sessions List sessions, optionally filtered Query: ?projectId=X. Response: Session[]
GET /sessions/latest Get the most recent session Query: ?projectId=X (optional). Returns latest session scoped to project or global.
GET /sessions/:id Get session by ID Response: Session

Queue

MethodPathDescriptionRequest / Response
GET /queue/status Get queue running state Response: { running: boolean }
POST /queue/pause Pause the queue Stops the poll loop. Response: { running: false }
POST /queue/resume Resume the queue Restarts the poll loop. Response: { running: true }

Prompt Improvement

MethodPathDescriptionRequest / Response
POST /prompt/improve Improve a prompt using AI Body: { prompt, action }. Action: reformulate | improve | correct | shorten | expand. Response: { result, action, original }.

SSE Events

Connect to GET /api/events to receive real-time server-sent events. Each event is a JSON line prefixed with data: :

EventPayloadDescription
job-startedJobA job began execution
job-completedJobA job finished successfully
job-failedJobA job exited with a non-zero code
job-cancelledJobA job was cancelled before starting
job-retryingJobA job failed and is being retried
job-heartbeat{ jobId, elapsed, logSinceLast }Periodic heartbeat while job is running
statsQueueStatsQueue statistics update (on each poll tick)

On connect, the server immediately sends a stats event with current queue counts.

Examples

Create a job

curl -X POST http://localhost:3457/api/jobs \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Refactor auth middleware",
    "prompt": "Review src/middleware/auth.ts and suggest improvements for token validation, error handling, and performance.",
    "model": "claude-sonnet-4-6",
    "tags": ["refactor", "auth"],
    "timeoutMs": 300000
  }'

Create a project

curl -X POST http://localhost:3457/api/projects \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-app",
    "rootPath": "/home/user/projects/my-app",
    "settings": {
      "contextFiles": ["README.md", "CONTRIBUTING.md"],
      "defaultModel": "claude-sonnet-4-6",
      "defaultExecutionMode": "api"
    }
  }'

Chatbot ask

curl -X POST http://localhost:3457/api/chatbot/ask \
  -H "Content-Type: application/json" \
  -d '{
    "projectId": "abc12345",
    "question": "How is the authentication flow structured?",
    "conversationId": "def67890"
  }'

Improve a prompt

curl -X POST http://localhost:3457/api/prompt/improve \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "fix the login bug",
    "action": "expand"
  }'

Move a ticket

curl -X POST http://localhost:3457/api/tickets/tkt001/move \
  -H "Content-Type: application/json" \
  -d '{ "column": "in-progress" }'

StatusMeaning

runningCurrently executing
retryingAuto-retry after failure
completedExit code 0
failedNon-zero exit, retries exhausted
cancelledCancelled before execution
stoppedKilled during execution (SIGTERM)
